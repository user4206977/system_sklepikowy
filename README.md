# 🏫 Zegowska Szama – System Zamówień Sklepiku Szkolnego

## 📌 Opis projektu
Projekt „Zegowska Szama” to aplikacja webowa umożliwiająca uczniom i nauczycielom przeglądanie oferty szkolnego sklepiku oraz składanie zamówień online.

System pozwala również administratorom (obsłudze sklepiku) zarządzać użytkownikami, produktami, promocjami oraz zamówieniami.

Projekt jest realizowany w ramach pracy zespołowej i znajduje się obecnie w fazie rozwoju.

---

## 🎯 Założenia projektu

Główne cele aplikacji:
- umożliwienie rejestracji i logowania użytkowników
- przeglądanie produktów dostępnych w sklepiku
- składanie zamówień online (koszyk)
- dostęp do promocji dla zalogowanych użytkowników
- panel administratora do zarządzania:
  - użytkownikami
  - produktami
  - zamówieniami

---

## 🛠️ Technologie

- **Backend:** PHP  
- **Frontend:** JavaScript + Bootstrap  
- **Baza danych:** MySQL  
- **Hosting:** zewnętrzny serwer (np. hosting współdzielony)
